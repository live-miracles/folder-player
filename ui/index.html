Base vMix Preset

Choose a default preset. A nearby `base.vmix` overrides it. For overlays, title base inputs `Cam` and `Mic`.

        v
Content folder
  |-- base.vmix        <- used first, when present

Parent folder
  |-- base.vmix        <- fallback for child folders
  |-- Session A

Cam  - camera input
Mic  - microphone input

Content Folder

Number files to set order. Same number means overlay, `+` reuses an overlay, and unnumbered items are ignored. Configured subfolders with `folder-player.txt` get their own presets. 

Content folder
  |-- 01 Welcome.mp4
  |-- 02 Teaching.mkv
  |-- 03 Meditation.mp3
  |-- 03 Slide.png        <- overlays 03 Meditation.mp3
  |-- 04 Deck.pptx        <- PowerPoint slideshow
  |-- 05 Photos           <- folder slideshow
  |   |-- image-1.jpg
  |   |-- image-2.jpg
  |-- Notes.txt           <- ignored

Same-number overlay:
07 Audio.mp3
07 Image.png
=> 07 Audio.mp3 + Image.png overlay

Underscore ordering:
03_1 Intro.mp4
03_2 Teaching.mp4
03_3 Meditation.mp3
=> plays 03_1, then 03_2, then 03_3

Reusable overlay:
03 Audio.mp3
08 Audio.mp3
03+08 Photos
=> Photos overlays both 03 and 08

Custom Parent Folder

When Custom Parent Folder is filled, generated preset input paths replace only the folder path before the playlist source folder. If a nearby base preset is found, the base preset parent folder name is kept. If the default base preset is used instead, the content folder parent is replaced. 

Nearby base preset:
Base preset: C:\a\b\base file.vmix
Media file:  C:\a\b\content\video.mp4
Custom:      C:\custom\path
Generated:   C:\custom\path\b\content\video.mp4

Default base preset fallback:
Media file:  C:\a\b\content\video.mp4
Custom:      C:\custom\path
Generated:   C:\custom\path\content\video.mp4
